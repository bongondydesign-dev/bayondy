# Crédits photo — `public/images/`

Aucune photo externe ni photo de personne n'est stockée ou utilisée à cette étape.
Toute image ajoutée dans `public/images/` doit obligatoirement figurer dans le tableau ci-dessous **avant** d'être affichée sur le site.

## Conventions techniques

- **Couvertures de formations** : format `16:9` (`1280×720` px), WebP, cible `< 150 Ko`.
- **Portraits (instructeur)** : format carré (`1:1`) ou `4:5`, WebP.
- **Visuels de remplacement actuels** : CSS et SVG de marque (symbole B-Portail sur fond `#080B14`).
